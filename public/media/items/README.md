### How to Replace:
Jab bhi aapke paas apni real product pictures hon:
1. Apni picture ko `.jpg` ya `.webp` format mein save karein.
2. Upar di gayi table ke mutabiq exact filename rakhein (maslan `inferno-hot-wings.jpg`).
3. Is folder (`public/media/items/`) mein paste (replace) kar dein.
4. Website automatically nayi picture show karne lagay gi bina kisi code change ke!
